# WP-022｜跨生态事件可信见证与多方一致性验证研究证据登记

**日期：** 2026-11-15  
**状态：** Research Evidence / Candidate Design  
**边界：** 参考技术原语不等于 Agent Ecology 已部署或完成互操作。

| 来源 | 类型/状态 | 已有机制与证据 | WP-022 借鉴点 | 适用边界 |
|---|---|---|---|---|
| RFC 9162 Certificate Transparency v2 | IETF Experimental RFC，2021-12 | Merkle inclusion/consistency proof、Signed Tree Head、Monitor；明确指出日志可向不同客户端提供冲突视图，Gossip 检测并未在 RFC 中定义 | 以独立 Monitor 比较 Checkpoint，检测 Log split-view | 仅为 CT 实验性协议；不能把 RFC 9162 描述为已标准化的通用 Gossip 协议 |

## 证据判断

- **已形成的技术原语：** Merkle inclusion/consistency proofs、Signed Checkpoint、Witness Cosignature、Witness 单调状态、K-of-N Quorum、分组策略、独立 Monitor、透明声明 Receipt。
- **规范状态必须区分：** RFC 9162 是 Experimental；RFC 9943 是 Proposed Standard；C2SP 是社区维护规范，v1.1.0 是其文档所标注的最新发布版本；Sigsum 部分协议稳定、部分文档仍 WIP。
- **WP-022 尚未验证的组合：** 将 Witness Quorum 绑定到 Agent Ecology Peer Binding；同时约束运营域与故障域独立性；跨接收方 Gossip；分叉证据的可复核治理闭环。
- **数学边界：** 公式 2q-n>f 只在固定成员集合、Witness 状态持久且诚实节点拒绝不一致历史的模型下保证任意两个 Quorum 的交集中至少存在一个诚实 Witness。它不抵御超过 f 的串谋，也不能证明运营独立性。
- **实施建议：** 先完成策略模型、状态机、确定性验证器和故障注入；再决定是否采用 C2SP Witness Protocol 适配，不在本轮部署全局透明日志。
