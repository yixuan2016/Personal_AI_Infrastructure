# WP-024｜TLA+ 形式化模型变量与性质目录

**状态：** TLA+ Source Created / TLC NOT_RUN  
**范围：** 有限状态 Witness Checkpoint 恢复与双签模型；可执行 TLA+ 源文件位于 formal/WitnessRecovery.tla，三份 TLC 配置已创建，但 TLC 尚未运行。

## 1. 模型常量

- Witnesses：有限 Witness 身份集合。
- Origins：有限 Log Origin 集合。
- Checkpoints：有限 Checkpoint 候选集合。
- Byzantine：配置允许的恶意 Witness 身份集合。
- QuorumThreshold：当前策略 q。
- RegistryVersion / PolicyVersion / TrustRootVersion：有限版本域。
- RecoveryCap：允许的状态擦除恢复身份上限。
- FailureDomains：运营、管理、密钥托管、备份和部署故障域集合。

## 2. 状态变量

| 变量 | 含义 |

| latestCheckpoint[w][origin] | Witness 已接受的最新 Checkpoint |
| durableState[w][origin] | 已持久化的防双签状态 |
| externalHighWater[w][origin] | 独立观察到的外部状态高水位 |
| membershipEpoch[w] | Witness Membership Epoch |

| partitionView | 当前网络分区和可达关系 |
| acceptedBundles | 已被验证器接受的证据集合 |

## 3. 关键动作

1. ProposeCheckpoint：收到待验证 Checkpoint。
2. VerifyConsistency：检查来源签名、Tree Size、Root Hash 和 Merkle Consistency Proof。
3. PersistState：持久化安全相关状态。
4. ReleaseCosignature：仅在 PersistState 成功后释放签名。
5. Crash：进程崩溃，区分安全状态保留与丢失。
6. RestoreSnapshot：从快照恢复，并与外部高水位核对。
7. RollbackAttempt：尝试恢复低于已知高水位的状态。
8. CloneIdentity：同一身份/密钥在多个实例中并发出现。
9. RevokeKey：撤销 Key Epoch。
10. PartitionNetwork / HealNetwork：创建或修复网络分区。
11. UpdateMembership / UpdatePolicy：执行版本化成员和策略迁移。
12. AcceptQuorumBundle：验证唯一签名身份、策略版本和故障域门槛。

## 4. 必须检查的不变量

- I1：同一 Witness/Origin 的 Tree Size 单调不减。
- I2：同一 Tree Size 只能对应一个被接受的 Root Hash。
- I3：每个 Tree Size 增长都具备有效一致性证明。
- I4：任何已释放签名都有对应的已持久化状态。
- I5：恢复不能使状态低于外部可信高水位。
- I6：同一身份不能在未协调的克隆实例中重复签名。
- I7：Quorum Bundle 中签名者身份唯一。
- I8：Quorum Bundle 的 Trust Root、Registry、Policy 版本一致。
- I9：有效 Quorum 满足签名阈值与独立故障域门槛。
- I10：故障或分区不能自动降低 Quorum 阈值。
- I11：已撤销密钥或过期策略不得重新获得签名资格。
- I12：无法证明恢复连续性时 Witness 必须保持隔离。

## 5. 必须构造的反例模型

### M1：持久化前签名
若 ReleaseCosignature 先于 PersistState，构造 Crash 后状态丢失并再次签名的反例。

### M2：状态快照回滚
若 RestoreSnapshot 可以覆盖更高的已知状态，构造同一 Witness 身份对冲突 Checkpoint 再次签名的反例。

### M3：身份克隆
若同一签名身份可在两个隔离实例中同时运行，构造两个实例分别接受不同 Checkpoint 的反例。

### M4：自动降低 Quorum
若分区时 q 自动降低，构造两个策略版本或不同 Peer 视图错误接受证据的反例。

## 6. 安全模型与活性模型分离

安全检查不得依赖“网络最终恢复”才能成立。活性检查必须显式增加网络最终同步、故障恢复和可达节点数量等假设。

TLC 完成有限模型探索，只能说明给定常量、状态域和假设范围内未发现违反；不能自动推广到任意 n、真实密码学、实际存储或组织控制关系。
