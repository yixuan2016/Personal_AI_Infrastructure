# Agent Ecology｜群体智能生态架构研究

本目录按版本保存 V1.2—V1.7 的研究报告、机器可读契约、架构图 SVG、验证矩阵和研究证据。

## 版本导航
- V1.2：协议契约与协作机制冻结设计
- V1.3：群体智能、自组织协作与 ADS 生态融合
- V1.4：Environment Runtime 运行时架构
- V1.5：群体智能经济与生态自治
- V1.6：生态世界模型与群体智能数字孪生
- V1.7：生态级 RSI 与递归进化治理

## 统一边界
Environment 是真实状态权威源；World Model/Twin 只产生预测和仿真状态；RSI 只创建候选，不签发生产授权；人类治理外环保留根策略、审批、否决、接管和问责权。

## 资料形态
Markdown、CSV、JSON、YAML 和 SVG 源文件纳入 Git。8K PNG、Word、PDF 和 ZIP 交付文件另行提供；SVG 可无损渲染为 8K PNG。所有尚未执行的测试保持 NotRun/待验证，不以资料入库代替工程验收。
