# 08｜接口、事件与错误码（候选）

## 1. API 资源

建议采用 HTTPS + mTLS/工作负载身份，签名内容摘要，版本化路径。具体协议栈可替换，但语义契约不得弱化。

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/federation/v1/members/claims` | 提交成员生态身份声明 |
| GET | `/federation/v1/members/{domain_id}` | 查询成员声明与撤销状态 |
| POST | `/federation/v1/capabilities/advertisements` | 发布能力广告 |
| POST | `/federation/v1/tasks/negotiate` | 协商跨域任务契约 |
| POST | `/federation/v1/policy/compatibility-checks` | 请求策略兼容评估 |
| POST | `/federation/v1/improvements/proposals` | 发布改进提案 |
| POST | `/federation/v1/evidence/bundles` | 提交证据包索引 |
| POST | `/federation/v1/adoptions/receipts` | 提交本地采用回执 |
| POST | `/federation/v1/revocations/events` | 发布撤销事件 |

- `FederationMemberSuspended`
- `CapabilityAdvertised`

- `FederatedTaskAuthorized`

- `ImprovementCanaryStarted`
- `ImprovementAdoptedLocally`

事件只声明发生了什么，不代表订阅者已经授权执行事件建议的动作。

## 4. 幂等与一致性

所有创建/变更请求必须包含 `idempotency_key`、`request_digest`、`actor_domain`、`policy_version` 和 `expires_at`。事件消费者以 `(producer_domain, event_id)` 去重，并检查单个 Owner 聚合内的 sequence/watermark。不能跨 Owner 比较序列号，也不能用接收时间替代事件因果关系。
