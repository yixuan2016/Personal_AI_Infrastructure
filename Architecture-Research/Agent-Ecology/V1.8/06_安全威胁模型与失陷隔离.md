# 06｜安全威胁模型与失陷隔离

## 1. 信任边界

- TB1：单个 Agent 进程。
- TB2：单个生态内部的 ADS / Environment / PDP / PEP。
- TB3：生态联邦边界与导出网关。
- TB4：联邦目录、事件中继和协调平面。
- TB5：其他生态的 Agent、工具与执行环境。
- TB6：人类治理身份、根密钥与生产授权。

## 2. 主要威胁

| 威胁 | 影响 | 核心控制 |
|---|---|---|
| Sybil/身份冒充 | 伪造多个生态或能力主体 | 身份绑定、运营者证明、配额、撤销 |
| 恶意能力广告 | 将不可用/恶意能力注入目录 | 签名声明、挑战验证、目录不作信任根 |
| 声誉串谋 | 虚增信誉与能力排序 | 独立来源分析、背书图检测、抽样审计 |
| 跨域提示注入 | 利用外部内容诱导越权 | 输入隔离、来源标记、工具最小权限 |
| 改进包供应链攻击 | 恶意 Prompt/工具/模型更新 | 内容摘要、签名、SBOM/依赖清单、沙箱 |
| 证据投毒 | 操纵评估数据或报告 | 数据谱系、独立评估、基线与复现 |
| 策略降级 | 以旧版本绕过新限制 | 版本下限、签名、执行前动态校验 |
| 事件重放/乱序 | 重复执行或状态错乱 | Nonce、序列号、水位、幂等键 |
| 联邦协调者失陷 | 错误路由/目录污染 | 多源发现、本地校验、无生产凭证 |
| 单生态失陷 | 横向扩散到其他域 | 域隔离、短时授权、撤销和断路器 |
| 数据外泄 | 私有记忆/业务数据泄露 | Export Policy、DataUseGrant、DLP |
| 模型更新投毒 | 跨域模型行为受污染 | 默认禁用参数聚合、隔离验证、回滚 |

## 3. 失陷处置

1. 冻结受影响域的联邦导出与新授权。
2. 撤销或暂停相关身份、能力声明和证据凭证。
3. 各接收生态查询本地采用记录，定位受影响候选与版本。
4. 按风险级别暂停 Shadow/Canary/生产版本。
5. 保留审计证据，禁止删除或改写事故记录。
6. 独立评估是否需要回滚、密钥轮换、重新签发身份。
7. 由各生态治理 Owner 分别决定恢复；不得由联邦协调者单方面解除隔离。

## 4. 不可突破的安全不变量

- 联邦目录无权直接触发生产动作。
- 外部 Agent 内容永远是非可信输入。
- 来源生态的批准不能替代接收生态的批准。
- 签名只能证明来源与完整性，不能证明内容正确。
- 信誉不能抵消授权缺失。
- ABSTAIN 不能自动升级为 ALLOW。
- RSI 不能修改人类根策略、根身份和权限上限。
- 任何跨域数据访问必须有目的、范围、期限和撤销机制。
