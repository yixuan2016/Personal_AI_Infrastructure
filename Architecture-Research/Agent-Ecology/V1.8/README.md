# Agent Ecology V1.8｜跨生态联邦进化与多生态协同治理

**版本：** V1.8-Architecture-Draft  
**日期：** 2026-11-10  
**性质：** 架构研究与候选契约，不是生产实现或互操作验收结论

## 本版本要解决的问题

V1.2—V1.7 已建立单一生态内部的环境状态、痕迹协作、运行时、生态经济、世界模型/数字孪生与 RSI 进化治理基础。V1.8 将边界扩展到多个自治生态之间：如何共享能力、证据与经验证的改进，同时不形成一个凌驾于各生态之上的中央控制者。

## 设计结论

1. **生态主权分治：** 每个生态拥有本地 ADS、Environment Runtime、Ontology、策略权威、数据权威和本地执行边界。
2. **联邦协调不等于中央控制：** 联邦协调平面只提供发现、协商、契约交换、证据索引和事件路由，不取得成员生态的本地执行权。
3. **环境状态优先：** 以共享环境中的状态、任务契约和可验证事件驱动协作；A2A 等消息协议承担寻址、协商与传输，不替代状态权威或授权判定。
4. **策略不做危险平均：** 本地硬约束不可被联邦策略放宽；冲突无法证明兼容时返回 ABSTAIN/HOLD。
5. **改进候选跨域传播，生产采用本地决定：** 一份改进提案可以共享，但每个生态必须独立验证、Shadow、审批和发布。
6. **信誉多维且有上下文：** 不以单一总分决定信任；身份、授权、能力、证据质量、时效、负面事件分别评估。
7. **数据最小化：** 默认交换签名元数据、能力声明和可验证证据摘要，不默认交换原始轨迹、私有记忆、策略全文或训练数据。
8. **人类外环不可绕过：** 根策略、根身份、权限上限、生产凭证和跨域数据授权不得由 RSI 自主修改。

## 与前序版本的关系

- V1.6 世界模型/数字孪生提供本地候选改进的预测与反事实验证能力；不得作为真实状态权威。
- V1.7 RSI 生成、评估和管理改进候选；不得签发跨生态生产授权。
- V1.8 为多个生态之间定义联邦发现、证据交换、策略兼容、采用回执和撤销机制。
