# V1.7 人类治理与不可自改边界

## 不可由 RSI 自主修改的根层对象
- 人类根策略及其授权主体；
- 身份根信任、密钥根和授权签发根；
- 人类审批、否决、接管和问责权限；
- 生产环境隔离边界和安全审计机制；
- 个人数据、领域数据权属与用途授权边界。

## 候选改进的权限边界
- RSI 只创建候选，不签发生产 Mandate。
- Sandbox 不持有生产凭证，默认网络隔离。
- Twin 只读生产投影，不可直接写回 Environment。
- 生成器不得读取隐藏测试标签或修改独立评估器。
- 任何跨域模式由领域 Owner 自主验证、适配或拒绝。
- 审批服务不可用时停止新版本发布，稳定版本继续运行。

## 责任链
候选作者 → 独立评估者 → 安全/领域审查 → 人类授权主体 → 发布执行者 → 独立验收者。关键高风险角色不得由同一 Agent 自行兼任。
