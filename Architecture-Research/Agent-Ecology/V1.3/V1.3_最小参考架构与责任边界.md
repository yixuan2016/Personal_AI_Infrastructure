# V1.3 最小参考架构与责任边界

## 试点拓扑
- 1 个逻辑共享 Agent Environment；物理上可由本地服务与云端授权投影共同组成。
- 3 个 Agent：Explorer、Synthesizer、Verifier。
- 1 个 ADS 治理/协调节点。
- 1 名人类治理者。

## 责任边界
- Explorer 生产来源、观察和候选证据，不自行批准结论。
- Synthesizer 读取授权证据并形成综合成果，不篡改原始证据。
- Verifier 独立验证成果，不由生产 Agent 自我验收。
- ADS 管理跨域语义、身份、能力、策略、预算、审计和风险升级。
- 人类对关键授权、高风险操作、生态级发布保留否决和接管权。

## 关键技术约束
1. State Plane 是任务权威状态来源；Trace Plane 只追加记录状态变化和证据。
2. 原子认领使用 CAS；租约续期使用版本条件；受保护写入校验递增 Fencing Token。
3. 事件发布采用事务性 Outbox；消费端采用 Inbox/幂等键；重复事件不得重复产生外部副作用。
4. 搜索、订阅和热度排序是派生投影，允许最终一致；授权、认领和撤权不能依赖陈旧投影。
5. 领域本地 PEP 对数据访问做最终执行检查；跨域默认最小投影。
6. 生产 Agent 与 Verifier 分离；关键结论必须保留原始来源和独立证据。
7. RSI 候选须独立评估、Shadow、审批、Canary、监控与回滚。

## 试点通过条件
- Agent 可从环境自主发现并认领任务。
- 无双重有效执行权；旧 Fencing Token 写入被拒绝。
- Agent 失效后，其他 Agent 能安全接续。
- 成果和证据可追溯到来源、版本和因果链。
- 未授权数据不进入跨域投影；撤权后新请求被拒绝。
- Verifier 可独立拒绝成果并发布反证。
- ADS 不接管领域专业验收。
- RSI 候选不得绕过独立评估和人类治理。
