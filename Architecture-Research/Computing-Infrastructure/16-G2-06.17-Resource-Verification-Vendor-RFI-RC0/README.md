## 本轮关键判断

- “规划容量”“申请容量”“研究可接入容量”“条件分配容量”“合同firm容量”“已建成容量”“已获准送电容量”“现场实测容量”必须作为不同字段记录，不能互相替代。
- 运营商可租机柜、园区已有MW、utility服务区统计和公共电网规划都不等于本项目获得资源。
- ERCOT 2026-11-05公布的177.4GW属于大型负荷互联申请/问卷所反映的请求峰值总量，不是可供分配电力；且大型负荷冷却问项仍有较高未答复比例，说明项目成熟度与设施配置尚有缺口。
- 中国多用户绿电直连政策仅在项目选择该模式时适用；须明确主责法人、产权、运行维护、内部平衡、结算、并网责任与计量，不可将“有绿电资源”直接视为稳定firm MW。
- 优先采用证据成熟度E0—E4和C0—C6容量状态双标签；未达项目级书面证据的硬门禁不得评分放行。

## 当前状态与限制

没有收到任何真实供应商答复、项目级容量函、地块/套间租赁要约、utility并网研究、正式电价/水价、OEM签署QVL、工程师签署设计或现场FAT/SAT。因此本阶段只能建立问询和证据审查工作包，不能宣称任何候选园区可用或三路线已有真实价格排名。
