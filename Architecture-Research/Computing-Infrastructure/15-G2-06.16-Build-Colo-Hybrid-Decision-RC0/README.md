## 决策范围

三条可投用路线：
- **A 完全自建**：业主自有或长期控制土地/设施，建设供配电、冷却、消防、园区网络和IT。
- **B 高密度托管入驻（Colocation）**：园区提供具备可核实容量的机房、电力、液冷及设施运维，业主部署和控制IT系统。
- **C 租赁机房/Powered Shell + 业主建设专属IT和部分机电**：场地/上游基础设施由运营商或业主出租，CDU/下游配电/IT视合同分工；这是“设施托管与自主算力”中间路线。

外部对照：公有云GPU租用可作为单位算力价格基线，不自动成为双区域十星同构节点，不把厂商云容量等价为NVLink物理域所有权。

## 暂定研究判断

在站点、负荷与租约条款未确定前，建议将**C作为优先核验路线，A作为长期自主权基线，B作为时间敏感备选**。这不是已完成的客观成本排名，也不是业主正式批准决定。

同一个双区域系统可以A区采用C、B区采用A或B，条件是资源Owner、本地安全联锁、部署接口、数据安全、RPO/RTO和双区域共同故障域分别通过验证。不能仅根据建筑产权推断算力自治权。

## 不可跳过的技术边界

- HPE NVL72名义TDP132kW、EDPp约155kW、busway planning192kW：三者口径不同，192kW不是平均IT功率或电力公司容量承诺。
- 8个Power Shelf分别有Power Whip；不预设8条电源馈线等同于端到端2N，也不预设单路失电无影响，必须按OEM电气单线图/故障模式验证。
- CDU 1.3MW是额定冷量，不是泵电耗，也不等于CDU整机N+1。一次侧和技术冷却系统（TCS）二次侧边界必须有书面接口表。
- 不能把机房运营方给出的“高功率密度”宣传语当成可供本项目的已锁定电力与液冷容量。
- 园区承诺可用率、SLA赔偿和电网firm MW属于不同层级；赔偿金不等于业务连续性。
- D/E/W/F/S站点硬门禁全部适用，新增合同可执行性与维护控制边界门禁。

## 当前结论

没有具体P4可交易地块/确定租赁机房、项目级firm MW、正式商业报价、完整OEM QVL、设施接口签署和现场故障验收。因此三路线暂不进行“谁最便宜/谁最快”的真实排名，所有TCO和评分保持待回填。
