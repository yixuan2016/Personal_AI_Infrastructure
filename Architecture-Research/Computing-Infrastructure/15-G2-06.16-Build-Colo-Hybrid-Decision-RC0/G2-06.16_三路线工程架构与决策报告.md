# G2-06.16｜三路线工程架构与决策报告

## 1. 要决策的不是建筑产权，而是可交付且可治理的算力能力

双区域十星需要五个逻辑星位：GPU、CPU/HPC、Storage、Control、Edge/Security。每个区域还需独立电力/冷却/网络/安全自治。设施“自建/托管”的不同会改变投资现金流、设备维护责任、资产风险和本地硬联锁，但不应改变Site LCP、PDP/PEP、资源Owner的授权及租约边界。

## 2. 三路线拆解

### A 完全自建（Greenfield / Owner-built）

业主负责土地/建筑或长期控制、变配电/UPS/发电机、CDU一次/二次侧、消防、结构、WAN入口和IT设备；可以外包运维，但责任保留合同明确的最终主体。

优势：独立设施治理权、定制机柜液冷和空间、持续扩容设计灵活；设施与IT资产的生命周期可按需调整。

限制：高初始CAPEX、许可/电网接入/水务/结构复杂、工期受到长交期设备约束，需自建24×7机电与安全运维组织。

适用：长期稳定负载、高利用率、大规模扩容，且已取得合规地块、firm MW、水权/冷却、运营商和建设资金。

### B 高密度托管入驻（Liquid-ready Colocation）

园区提供可租用机房、供电、冷源/CDU（具体以合同为准）、物理安全及设施24×7运维；业主自有GPU、存储、交换机、密钥与工作负载控制。应逐项区分“园区一次侧就绪”“运营商提供CDU”“仅提供水接入点”“全套二次侧可用”。

优势：可利用既有工程许可和设施团队，减少部分建设/运维复杂性；适于中短期与快速需求（仅当实际容量与服务可交付）。

限制：预留kW/机柜/液冷能力可能被其他租户共享；对供应商停机维护、冷却液/水质、机柜门禁和CDU操作的控制受合同限制；续租/涨价/退出成本。

适用：供应商可书面锁定准确机柜空间、连续供电与液冷、现场访问、端到端故障测试和专属隔离。

### C Powered Shell / Dedicated Suite + 自建IT（混合所有权）

园区交付带明确接入能力的建筑或独立套间/机房、上级电源/水源/消防基础设施；业主在合同约定边界内安装独立PDU/母线、CDU或其二次侧、GPU Fabric、存储/控制和本地安全联锁。CDU归属可选运营商、业主或联合维护，**必须在RACI表中只有明确的动作Owner和安全责任**。

优势：保留核心IT、网络、安全和可选二次液冷控制，避免全绿地建设；有机会形成独立故障域和扩容路径。

限制：设施界面最复杂，容易出现“CDU谁操作/谁审批停机/谁承担漏液赔偿”的责任缝隙；租约/设施改造验收/退租恢复约束高。

适用：已存在合法高密设施、可单独计量、允许专属设备安装、供电/水务服务边界可签署、24×7安全干预明确的园区。

## 3. 生命周期/弹性对照

| 项目 | A 完全自建 | B 高密托管 | C 租赁设施+自建IT |
|---|---|---|---|
| 土地/建筑 | 业主承担 | 运营商 | 运营商或长期租赁 |
| 电网大负荷接入 | 业主主导 | 园区主导（仍须锁定项目容量） | 园区主导/合同分摊 |
| UPS/PDU/Whip | 自建与维护 | 服务合同明确 | 分段所有权/工程接口 |
| 设施一次侧 | 自建 | 园区 | 园区 |
| CDU/二次侧 | 自建 | 依合同 | 推荐专属或独立管理 |
| GPU/存储/Control | 业主 | 业主 | 业主 |
| 光纤入楼/双运营商 | 业主确认 | 园区提供通道+业主审查 | 分段负责 |
| 建设许可/环评 | 业主组织 | 园区既有许可需验证覆盖范围 | 双方承担各自改造许可 |
| 成本结构 | CAPEX较高（待报价） | OPEX租赁占比可能较高（待报价） | 设施租费+专属设备CAPEX |
| 退出/迁移 | 资产处置和土地运营 | 退租/搬迁/液冷排放 | 退租复原/专属设施拆除 |
| 交付速度 | 受许可与接入影响 | 实际“就绪容量”才可能快 | 介于两者；看接口改造 |

**以上成本与工期是结构性假设，不是三路线已经实测的排名。**

## 4. 双区域三种部署组合

- A+A：两个独立自建站，控制权最大；同时建设资本投入、机电团队及供应链能力压力也高。
- C+C：两区专属套间/二次侧+自有IT，满足真正故障域隔离时可兼顾自主权与资源复用。
- B+C 或 B+A：时间敏感区域采用托管，自建/混合区域承接长期容量。租赁方故障不应影响另一区域本地Owner与权限管理。

任何组合必须核验电网/变电站、冷却水/流域、运营商/批发光纤、消防、数据法域、IAM/PKI/DNS/审计、OEM服务与备件共同故障点。

## 5. 业务与性能边界

- NVLink构成单机柜高带宽域，不能因跨区网络互联即视为一个NVLink物理域。
- GPU Fabric双平面是各区域本地高速通信；跨区只在业务SLO可接受的前提下承担异步Checkpoint/数据复制、控制协调、工作负载迁移。
- 异步复制的RPO/RTO由数据变化率、带宽、恢复容量、完整性验证决定，不能由线路标称Gbps直接推断。
- 多租户托管需核验光模块/光链路、OOB与Facility物理隔离；不能把园区统一BMS接口直接暴露给业务AI Agent。

## 6. 建议决策过程

G0 确认真实负荷与国家法域 → G1 锁定可交易地块/套间 → G2 项目级firm MW和供液/冷源 → G3 物理网络与共同故障域 → G4 RACI/远程支持/安全联锁 → G5 E3工程签署与FAT/SAT → G6 正式报价及同口径五年TCO → G7 业主批准。

本轮未获得G1—G7实际项目证据，不能宣布任何一条路线已经最优。
