# G2-06.10｜双区域十星 OEM 级整机与配置参考架构

**核查日期：** 2026-11-14  
**状态：** RC0 候选，待 OEM 与站点 Owner 评审  
**目标：** 将 G2-06.9 设备型号候选落实为可报价、可核验、可部署的 OEM 整机和单星配置。

## 1. 架构结论

十星采用“异构星位 + OEM 参考平台 + 区域级独立网络/设施”的配置方式，不要求十颗星使用同一服务器或同一 GPU 技术路线。

本阶段给出一套主参考组合：

- A1/B1：每区域 1 套 72-GPU GB300 NVL72 机柜级系统。
- A2/B2：每区域 1 套 Lenovo SC755 V5 + N1380 CPU/HPC 计算单元。
- A3/B3：每区域 2 台 Dell PowerEdge R7725xd 高容量 NVMe 存储服务器。
- A4/B4：每区域 3 台 Dell PowerEdge R9815 通用/控制节点。
- A5/B5：每区域 2 台 Dell PowerEdge R9815 网络/边缘服务节点，以及 2 台 800G GPU Fabric 交换机；另设独立 OOB 管理交换、WAN 路由/安全设备。

这是一套用于技术评审和预算建模的候选配置，不代表已确定采购数量。GPU 主参考以 HPE GB300 NVL72 为规格测算基线，Dell XE9712 与 Lenovo Type 7DJV 为整机对照。不同 OEM NVL72 不能把各自的托盘、供电和冷却部件混搭。

## 2. OEM 整机候选与角色

### 2.1 GPU 星：72-GPU rack-scale

**主参考：HPE NVIDIA GB300 NVL72 by HPE**

- 基础系统代码：S7K95A。
- 基础机柜：S6C60A。
- 混合冷却 compute tray：S6C59A。
- 机柜：48U。
- 计算托盘：18 个；每托盘 2 颗 Grace CPU、4 张 Blackwell Ultra GPU。
- GPU：72× NVIDIA B300。
- Grace CPU：36 颗。
- NVLink Switch Tray：9 个。
- 电源：8×33kW Power Shelf，50V DC Busbar。
- 机柜名义 TDP：132kW；EDPp 峰值约 155kW；HPE 建议母线按 192kW EDPp 配置。
- 液冷：CPU/GPU 冷板 + 机柜 manifold + Vertiv XDU1350 CDU。
- HPE QuickSpecs 列出的 XDU1350 CDU 选项 SKU：S5R40A/S5R41A/S5S27A/S5S28A；具体取决于一次/二次侧管路方向。
- 单台 XDU1350 额定冷量 1.3MW，HPE 声明最多支持 8 个该类机柜；现场仍须核验冗余、管路压降、流量和环境边界。
- 机柜长宽高、重量、供电和服务空间按 HPE QuickSpecs 与实际订货配置核对。

**OEM 对照：**
- Dell PowerEdge XE9712：GB300 NVL72，集成于 IR9048 48RU rack；每个 1RU sled 4 张 Blackwell Ultra GPU，机柜 72 GPU；PS33 33kW Power Shelf，支持 6×5.5kW PSU。
- Lenovo NVIDIA GB300 NVL72：Type 7DJV；18 个 compute tray、9 个 NVLink switch tray；每 tray 4×B300、2×Grace CPU、4 个 800Gb/s OSFP 接口；每 tray 双液冷回路；Power Shelf 可按配置采用 6 或 8 个。
- 采购比较必须把完整机柜、配电、冷却、交换、软件、维保和部署服务放在同一 TCO 口径下。

### 2.2 GPU 星：8-GPU node 备选

当任务不需要 72 GPU 单机柜 NVLink Scale-up 域，或需要降低单次采购门槛时，使用 8-GPU 节点路线：

**NVIDIA B300 路线**
- Dell PowerEdge XE9780L：3 OU 液冷节点，8× HGX B300 NVL8 270GB SXM6，8 GPU 由 NVLink 互连；可选 Intel Xeon 6 主机平台。
- Dell PowerEdge XE9785L：3 OU 液冷节点，AMD EPYC 9005 主机平台，8× HGX B300 NVL8；与 XE9780L 是不同 CPU 平台选项。
- Dell PowerEdge XE9780：10U 风冷 8-GPU B300 平台，适合未部署直接液冷基础设施的机房，但需核对机柜密度与风道。

**AMD MI355X 路线**
- Dell PowerEdge XE9785 / XE9785L：8× AMD Instinct MI355X 288GB 1400W OAM，AMD Infinity Fabric；分别有风冷与液冷形态。
- 不得把 MI355X OAM 模块当作通用 PCIe 卡；必须使用 OEM 完整服务器平台。
- CUDA/NCCL 与 ROCm/RCCL 软件栈、驱动、固件和容器镜像分别建立版本基线。

### 2.3 CPU/HPC 星：Lenovo SC755 V5 Neptune

**型号与平台：**
- ThinkSystem SC755 V5 Neptune Tray：7DN6CTO1WW，2×2-socket node 配置；或 CCKU 4×1-socket node 配置。
- ThinkSystem N1380 Neptune Enclosure：7DDHCTOLWW。
- 一个 N1380 enclosure 安装 8 个 SC755 V5 tray，13U。
- 2N2S 完整配置：16 个独立双路节点，每 tray 4 颗 CPU。
- 4N1S 完整配置：32 个独立单路节点，每 tray 4 颗 CPU。
- 每个 2-socket 节点 32 个 DIMM 槽，最高 4TB RDIMM（32×128GB）；支持 DDR5 RDIMM 8000MT/s 和 MRDIMM 12800MT/s。
- 官方支持的 CPU SKU 示例：EPYC 9976-S7（256C/512T/600W，非 Controlled）、9756-S7（128C/256T/500W）；EPYC 9996-S7 在该产品指南中标为 Controlled，采购地区必须确认。
- 不要将 AMD EPYC 9956 自动写入 SC755 V5 的冻结 BOM：Lenovo 当前公开处理器列表未列出 9956，需以最新 DCSC/QVL 为准。
- 内置网络：每个 2N2S 节点 2×25GbE，8 tray/16 node 时最多 32 个 25GbE 端口；高性能网络需按 PCIe 6.0/OCP 选配。

**供电和液冷：**
- N1380 最多 4 个水冷 Power Conversion Station，每个 15kW。
- 4 PCS 配置在 N+1 策略下的 DC chassis capacity 为 54kW（并非设备实际持续功耗）。
- 45°C 水温时，8 tray + 4 PCS 的示例流量为 42.8 L/min。
- 32°C 水温时，8 tray + 4 PCS 的示例流量为 34.8 L/min。
- 水质、过滤、缓蚀/抑菌、压力降和快速接头需遵循 Lenovo Neptune 标准。

### 2.4 存储星：Dell PowerEdge R7725xd + KIOXIA LC9

**单服务器参考配置：**
- OEM：Dell PowerEdge R7725xd，2U。
- CPU：双路 AMD EPYC 9005。
- 内存：24 DIMM，最高 3TB RDIMM。
- 驱动器：40× E3.L Gen5 NVMe（机箱具体背板/控制器和 SKU 需按 Dell 配置器确认）。
- SSD：KIOXIA LC9 E3.L 245.76TB，型号可选 RLC9CZV245T（SIE）、RLC9EZV245T（SED）、RLC9GZV245T（FIPS SED）；加密型号须通过 OEM QVL 和安全 Owner 核验。
- 单机原始容量：40×245.76TB = 9,830.4TB ≈ 9.83PB（十进制）。
- 盘功耗：按 KIOXIA 数据表 30W typ/drive，40 盘约 1.2kW。
- Dell 技术简报估算服务器本体 447W，装 40 盘后约 1.647kW；该值是厂商公开规格推算，不等同现场 PDU 实测。
- LC9 是 QLC、读密集型、0.3 DWPD，适合大容量数据湖/对象数据池；不作为高写入事务账本或元数据池的默认介质。

**每区域参考数量：** 2 台 R7725xd，原始容量约 19.66PB。两区域合计约 39.32PB 原始容量，未扣除纠删码、副本、元数据、格式化和预留空间。

**热数据层：** Micron 9650 PCIe Gen6 E1.S/E3.S 或 Micron 9550 PCIe Gen5，按主机兼容性、耐久、容量和散热确定；与 LC9 冷/容量层分池。

### 2.5 通用/控制星：Dell PowerEdge R9815

- 2U 单路服务器。
- 1× AMD EPYC 9006 SP7，最高 256 核。
- 16× DDR5 DIMM；最高 4TB RDIMM 或 2TB MRDIMM（以 Dell 具体配置为准）。
- 最多 16× EDSFF E3.S Gen6 NVMe；具体背板 SKU 和驱动器 QVL 待确认。
- 支持 PCIe Gen6 x16 插槽、OCP 3.0、iDRAC/Redfish、Secure Boot 和签名固件。
- 风冷与可选直接液冷形态均需按订单确认。
- 每区域 3 台作为控制/通用服务 HA 候选，另 2 台作为网络/边缘服务节点；最终角色与节点数需由业务负载、故障域和 quorum 规则确认。

### 2.6 网络/边缘星：GPU Fabric 与 WAN 分离

**GPU Fabric 方案 A：InfiniBand**
- NVIDIA Quantum-X800 Q3400-RA：4U，144×800Gb/s OSFP 端口，115.2Tb/s 总吞吐。
- 典型功耗：使用 passive cables 约 2.9kW；active cables 最大功耗可达 7kW。
- 每区域 2 台形成两个独立 Fabric Plane，按 72 条 rack 端口均分时每台初始接入约 36 条链路；实际需按 NIC rail、拓扑、上联和冗余设计复核。

**GPU Fabric 方案 B：Ethernet**
- NVIDIA Spectrum-6 SN6600：128×800Gb/s OSFP，102.4Tb/s。
- 典型功耗：FRO 光学约 3.94kW；TRO 约 3.2kW。
- SN6600-LD 液冷变体：FRO 约 3.3kW；TRO 约 2.79kW。
- 每区域 2 台构建 A/B 双平面；RoCE 的 ECN/PFC、拥塞控制、队列、MTU、路由与多租户隔离必须端到端验证。

**禁止混淆：** Q3400-RA 是 InfiniBand；SN6600 是 Ethernet。不能在未验证的情况下把两种网络作为一套无差别 Fabric。

**WAN 与管理网络：**
- 区域间 WAN 不承载默认的 GPU Scale-up；跨区域训练需单独验证通信时延、同步成本和故障语义。
- WAN 边界路由、防火墙、运营商 CPE、DDoS 防护、带外管理交换机型号待运营商/安全/站点 Owner 决策。
- BMC/Redfish/设施管理网与租户数据网络隔离。

## 5. 设备组合边界

- HPE、Dell、Lenovo NVL72 机柜级方案是替代选择，不能把一个 OEM 的电源、托盘、液冷 manifold 与另一个 OEM 的机柜拼装。
- Lenovo SC755 V5 是 CPU/HPC 节点，不支持 GPU 加速卡；GPU 工作负载放在专用 GPU 星。
- Dell XE9780L、XE9785L、XE9785 是 8-GPU 服务器平台，不是 NVL72 rack。
- R7725xd + LC9 容量层不应承担高写入事务账本。
- 800G GPU Fabric、Storage Fabric、Control/OOB、WAN 是不同网络域。
- 所有单机功耗、机柜功率、CDU 冷量和站点容量须分别计量，不可混算。
