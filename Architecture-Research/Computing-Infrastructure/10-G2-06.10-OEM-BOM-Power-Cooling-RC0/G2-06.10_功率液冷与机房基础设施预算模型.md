# G2-06.10｜功率、液冷与机房基础设施预算模型

**状态：** RC0 估算模型，待设施与 OEM Owner 复核  
**核查日期：** 2026-11-14  
**目标：** 将设备额定值、供电容量、实测功率、热负载和液冷能力分开，避免错误累加。

## 1. 预算口径必须分层

| 指标 | 含义 | 是否可直接相加 |
|---|---|---|
| CPU TDP / GPU TGP/TBP | 芯片或模块热设计/功率指标 | 不可直接代表整机输入 |
| PSU/Power Shelf 容量 | 电源设备可提供的最大输出能力 | 不等于持续负载 |
| Server input power | 服务器 AC/DC 输入实测或 OEM 估算 | 可按同一测量边界汇总 |
| Rack IT load | 机柜 PDU/母线测量的 IT 设备输入功率 | 可按区域汇总 |
| EDPp / 峰值设计功率 | 厂商用于电力基础设施规划的峰值口径 | 必须按厂商定义使用 |
| Cooling capacity | CDU/冷机可移除的热量 | 不是电力消耗 |
| Facility power | IT + 制冷 + 配电损耗 + 照明/安防等 | 由现场计量与 PUE 决定 |

严禁把 8×33kW Power Shelf 的 264kW 输出能力写成 GB300 NVL72 实际耗电量。

## 2. GB300 NVL72 机柜功率基线

以 HPE NVIDIA GB300 NVL72 QuickSpecs 为本阶段参考：

| 指标 | 单机柜 |
|---|---:|
| 机柜名义 TDP | 132kW |
| EDPp 峰值 | 约 155kW |
| HPE 建议母线规划能力 | 192kW EDPp |
| Power Shelf 数量 | 8 |
| 单个 Power Shelf 输出能力 | 33kW |
| Power Shelf 合计额定输出能力 | 264kW |
| DC Busbar | 50V |
| 机柜高度 | 48U |
| CDU | Vertiv XDU1350 |
| CDU 额定冷量 | 1.3MW |
| 厂商声明单台 CDU 支持机柜数 | 最多 8 个（按 HPE 方案说明） |

解释：
- 264kW 是 8 个 33kW Power Shelf 的合计额定输出能力，不是机柜运行功耗。
- 132kW 是名义 TDP，155kW 是 EDPp 峰值，192kW 是 HPE 建议数据中心母线规划值，三者不能互相替代。
- CDU 的 1.3MW 是热交换能力指标，需结合一次/二次侧流量、温度、压降、泵冗余和换热条件验证。
- 机柜配置的 8 个 Power Shelf 与实际供电冗余/负载策略需按 OEM 配置确认。

## 3. 双区域 GPU 机柜功率合计

主参考假设：Region A 与 Region B 各配置 1 套 HPE GB300 NVL72。

| 指标 | Region A | Region B | 双区域合计 |
|---|---:|---:|---:|
| 名义 TDP | 132kW | 132kW | 264kW |
| EDPp 峰值 | 155kW | 155kW | 310kW |
| 建议母线规划值 | 192kW | 192kW | 384kW |
| Power Shelf 合计额定输出 | 264kW | 264kW | 528kW |

以上仅为两套 GPU 机柜的厂商参考值之和，不包含 CPU/HPC、存储、R9815、Fabric 交换机、WAN、OOB、CDU 泵/控制、UPS 损耗和其他机房负载。不能将 384kW 解释为两个区域全部 IT 设备的总功率。

## 4. CPU/HPC N1380 电力与液冷

Lenovo SC755 V5 + N1380 官方规格：

- 1 个 N1380 enclosure 可装 8 个 SC755 V5 tray。
- 最多 4 个水冷 Power Conversion Station（PCS）。
- 每 PCS 额定 15kW。
- 4 PCS 在 N+1 策略下可提供 54kW DC chassis capacity。
- 4 PCS 无冗余理论合计 60kW，但不应按无冗余作为生产设计。
- 输入：380–480VAC，三相 WYE。
- 每个 PCS 输入 30A/相；电缆和配电按 OEM 规范。
- 45°C 水温时，每 tray 4.0L/min，每 PCS 2.7L/min。
- 8 tray + 4 PCS 示例总流量：8×4.0 + 4×2.7 = 42.8L/min。
- 32°C 水温时，每 tray 3.3L/min，每 PCS 2.1L/min；8 tray + 4 PCS = 34.8L/min。
- 45°C 是平台水温工况之一，不代表所有数据中心一次侧水温可直接设为 45°C；必须按 Lenovo Neptune 冷却标准和现场 CDU 能力确认。

双区域各 1 套 N1380：
- N+1 DC capacity 合计 108kW。
- 45°C 示例水流量合计 85.6L/min。
- 该 108kW 仍是电源可用容量，不是实际 IT 负载。

## 6. 800G Fabric 交换机功耗

### InfiniBand：Quantum-X800 Q3400-RA

- 4U，144×800Gb/s OSFP 端口。
- 总吞吐 115.2Tb/s。
- 典型功耗（passive cables）约 2.9kW。
- 最大功耗（active cables）约 7.0kW。
- 每区域 2 台：典型约 5.8kW；主动线缆最大约 14kW。

### Ethernet：Spectrum-6 SN6600

- 128×800Gb/s OSFP 端口。
- 交换容量 102.4Tb/s。
- 典型功耗：FRO 约 3.94kW；TRO 约 3.2kW。
- SN6600-LD 液冷型号：FRO 约 3.3kW；TRO 约 2.79kW。
- 每区域 2 台 SN6600：FRO 典型约 7.88kW；TRO 典型约 6.4kW。

IB 与 Ethernet 是替代路线，不得将两组功耗一起计入同一基线。光模块/线缆形态不同会显著改变功耗。

## 7. CDU 与冷却容量设计

### GB300 机柜

HPE QuickSpecs 提供 Vertiv XDU1350，额定冷量 1.3MW，并说明一台最多支持 8 个 HPE GB300 NVL72 机柜。两区域各一套 GPU rack 时，按厂商最大机柜数量看容量上限充足，但这不自动证明：
- N+1 CDU 冗余；
- 任一泵/电源/一次侧故障下的持续能力；
- 机房一次侧水温、流量和压降满足要求；
- 冷板/Manifold/快速接头/水质满足保修条件。

建议按每个区域独立冷却故障域设计；是否采用 1+1 CDU、N+1 泵、旁路和跨区域备援由设施 Owner 评审。不要把一个区域的 CDU 默认视为另一区域的故障备援。

### 热量和水流量的通用核算

水冷回路热交换基本关系：

Q = m_dot × Cp × ΔT

其中：
- Q：热负载（kW）；
- m_dot：质量流量（kg/s）；
- Cp：冷却介质比热容（kJ/kg·K）；
- ΔT：供回水温差（K）。

水的近似计算可用：
流量（L/min）≈ 14.35 × Q(kW) / ΔT(K)。

示例仅用于工程量级理解：若热负载为 155kW，假设水温升 10K，理论流量约 222L/min。该数字不是 HPE/NVIDIA 给出的机柜指定流量，不能替代 OEM 冷却曲线、冷板压降和 CDU 设计数据；使用乙二醇或其他冷却液时必须改用其真实密度和比热。

## 9. 设施设计必须补齐的内容

1. 每区域 IT 负载基线、峰值、瞬态和增长预留。
2. A/B 两路供电、UPS、PDU、母线、变压器和发电机容量。
3. 机柜功率密度、楼板承重、设备运输路径、吊装和维护空间。
4. 液冷一次/二次侧边界、CDU N+1、泵、阀、过滤、漏液检测、水质和排水。
5. 风冷余热：NIC/光模块/SSD/PSU/交换机仍可能存在空气冷却负载。
6. 消防、漏液、过温、过压、断水、断电联锁。
7. 设施告警、带外网络、Redfish/BMC 和本地安全控制的独立性。
8. 现场 PUE、WUE、IT load、冷却电力、功率因数和负载率实测。

## 10. 结论

当前可形成 GB300、SC755/N1380、R7725xd、Q3400/SN6600 的部分设备级功率/冷却基线；R9815、WAN、安全、OOB 和完整机房辅助负载仍待 OEM 配置器与设施设计。未取得各星位完整 BOM、区域供电/冷却图和 PDU 实测前，不给出十星总功率或机房总制冷量的伪精确数字。
