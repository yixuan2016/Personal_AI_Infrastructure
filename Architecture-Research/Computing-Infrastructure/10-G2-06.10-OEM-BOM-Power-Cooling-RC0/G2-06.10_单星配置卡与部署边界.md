# G2-06.10｜单星配置卡与部署边界

**状态：** RC0 候选；星位与设备数量待业务 Owner 确认  
**拓扑：** Region A：A1—A5；Region B：B1—B5

## A1 / B1｜GPU Scale-up 星

**主参考设备：** HPE GB300 NVL72 by HPE（S7K95A 基础系统代码）  
**OEM 替代：** Dell PowerEdge XE9712（IR9048）；Lenovo GB300 NVL72（Type 7DJV）

- GPU：72× B300。
- CPU：36× Grace。
- 机柜：48U。
- 计算托盘：18；NVLink switch tray：9。
- 机柜名义 TDP：132kW；EDPp：约 155kW；母线建议规划：192kW。
- 液冷：CDU + rack manifold + cold plate；本地设施安全联锁独立。
- GPU Scale-up 域仅限单机柜 NVLink fabric；跨区域不宣称为一个 NVLink 域。
- 数据集和 Checkpoint 走 Storage Fabric，不与 GPU Collective 无差别共享拥塞域。
- 关键 Owner：GPU、Rack System、Network Fabric、Facility、Data Owner。

**替代路线：** 每区域 4 台 8-GPU Dell XE9780L/ XE9785L 等价 32-GPU 规模。此路线的节点数、GPU 总数和单机柜 NVLink 域与 72-GPU NVL72 不等价，必须独立评估。

## A2 / B2｜CPU/HPC 与 Agent 执行星

**主参考设备：** Lenovo ThinkSystem SC755 V5 Neptune + N1380。
- N1380：13U，一个 enclosure 最多 8 个 SC755 V5 trays。
- 2N2S：16 个双路节点；4N1S：32 个单路节点。
- 2N2S CPU 候选：EPYC 9976-S7（256C/600W）或 9756-S7（128C/500W）；以地区供货和 OEM 配置器为准。
- 2S 节点最多 4TB RDIMM；每节点 32 DIMM。
- 4 PCS 的 N+1 DC capacity：54kW。
- 45°C 工况下完整 8 tray + 4 PCS 的示例水流量 42.8L/min。
- 节点之间保持 NUMA、租户、执行沙箱和本地权限隔离。
- 不承载 GPU 训练；GPU 工作负载交给 A1/B1。
- 关键 Owner：CPU/Memory、HPC Runtime、Network、Facility。

## A3 / B3｜存储与数据服务星

**主参考设备：** 2× Dell PowerEdge R7725xd / 区域。
- 每台 40× KIOXIA LC9 E3.L 245.76TB。
- 每台原始容量约 9.83PB；每区域两台约 19.66PB 原始容量。
- 盘型为 PCIe Gen5 QLC，0.3 DWPD，适合大容量读密集数据池。
- 高写入元数据、Saga Ledger、Lease/Owner 事务事实使用独立高耐久/低延迟存储池。
- 存储复制/纠删码、跨区域数据驻留、加密密钥和撤销策略由 Data Owner 决定。
- 关键 Owner：Storage、Data、Security/KMS、Backup/Recovery。

## A4 / B4｜控制面与通用服务星

**主参考设备：** 3× Dell PowerEdge R9815 / 区域。
- 2U 单路 AMD EPYC 9006 SP7。
- CPU 具体 SKU、内存、NIC 和 SSD 按 Dell QVL/配置器确认。
- 适合区域级 ADS/SCO/RCP/LCP 辅助服务、目录、监控、任务控制与 Agent 平台通用服务。
- 3 节点 HA/仲裁只是候选拓扑，需按服务一致性模型、独立故障域和仲裁规则验证。
- 不因节点共址而混合 Owner 权限；ADS/GCP、SCO、RCP、Site LCP 的数据与状态所有权分离。
- 关键 Owner：Platform、Control Plane、Identity、Security、Audit。

## A5 / B5｜网络边缘、安全与可观测星

**主参考设备：**
- 2× Dell PowerEdge R9815 / 区域，承载网络服务、安全代理、监控、遥测、日志采集和边缘任务。
- 2× 800G Fabric 交换机 / 区域：Quantum-X800 Q3400-RA 或 Spectrum-6 SN6600 二选一。
- 独立 OOB 管理交换机、WAN 路由器、防火墙、运营商 CPE 和时间源待区域网络设计冻结。

**边界：**
- GPU Fabric 与 Storage Fabric 分离。
- Control/OOB 与租户数据网络分离。
- P0 撤销、设施联锁、身份/密钥关键流量有独立优先级和本地执行能力。
- WAN 失联不代表站点可扩大离线权限。
- 关键 Owner：Network、Security、NOC、Facility、Carrier。

## 十星跨域共同规则

1. 星位编号只表示角色，不是固定物理地址。
2. 同一物理站点可承载多个星位，但必须有独立故障域和数据/权限边界。
3. 每个设备实例均有唯一资产 ID、Owner、位置、固件/驱动版本、保修和维护窗口。
4. BMC、Redfish、PDU、CDU 和交换机管理面进入独立管理网络。
5. 资源目录可发现设备，不代表资源可承诺；必须由对应 Resource Owner 做 Prepare/Commit。
6. 设备退役、固件升级和故障隔离要更新资产/拓扑/本体/证据记录。
7. 任何星位配置变化必须更新 BOM、功率预算、网络端口表、冷却模型和故障注入矩阵。

## 需要 Owner 补充的输入

- 每区域实际场地、机柜数、楼板承重、供电电压和可用 kW。
- GPU 训练/推理比例、模型大小、并发、tokens/s、训练规模与 SLA。
- Agent CPU 工作负载、虚拟机/容器密度、内存和本地 NVMe 需求。
- 存储数据量、增长率、读写比例、DWPD、数据驻留、RPO/RTO 和保留期。
- WAN 运营商、线路多样性、带宽、RTT、抖动、丢包与路由策略。
- 数据安全等级、密钥管理、审计保留、离线授权和撤销窗口。
