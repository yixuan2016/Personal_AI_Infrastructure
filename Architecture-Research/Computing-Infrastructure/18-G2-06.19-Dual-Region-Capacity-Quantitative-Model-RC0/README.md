## 可计算的候选算术基线
- GPU：每区1套GB300 NVL72候选、72 GPU；双区144 GPU候选。每区理论日历容量72×8,760=630,720 GPU-h/年，双区1,261,440 GPU-h/年；不是有效产出或可售算力。
- 存储：每区2台R7725xd、每台40×245.76TB候选盘，原始19.6608PB/区、39.3216PB/双区；未扣保护、热备、元数据、快照和运行水位。
- GPU 132kW TDP、约155kW EDPp、192kW母线规划是不同口径，不等于AC输入或Utility firm MW。
- N1380 54kW N+1 DC chassis capacity不是AC输入。
- XDU1350 1.3MW是额定冷量，不是电功率；泵N+1不等于整机1+1。
