# G2-06.14｜双区域组合路线与故障域分析

## 1. 决策原则

双区域不是“挑两个资源好的地方”即可。必须同时满足：
- 每个站点各自通过G2-06.13硬性门槛；
- A/B组合在电网、水源、网络、灾害、法律、供应链和控制依赖上具备可证明的独立性；
- 业务SLO、数据驻留、复制窗口和恢复目标可以实现；
- 每区域均可在WAN失联时保持本地安全自治。

## 2. 三条路线并行

### 路线A：中国大陆同国双区域

候选组合（仅用于下一轮尽调，不是推荐定案）：
1. 呼和浩特—和林格尔走廊 + 贵州贵安；
2. 甘肃庆阳 + 贵州贵安；
3. 宁夏中卫 + 贵州贵安；
4. 西部资源区 + 京津冀/长三角需求侧边缘节点。

优点：
- 国内数据驻留、合同、运维和合规治理链条相对简化；
- 可结合国家枢纽节点和算力网政策；
- 贵州南方电网服务区域与内蒙古/甘肃/宁夏的电网经营区域不同，有利于研究不同电力服务区组合，但并不代表完全电气隔离。

风险：
- 跨区域骨干网络、跨省数据传输和时延成本；
- 不同省份仍可能共享国家级输电/通信/供应链依赖；
- 数据分类、行业监管和省级政策仍须分别审查。

### 路线B：美国同国双区域

候选组合（仅用于下一轮尽调）：
1. ERCOT德州西部 + MISO候选utility；
2. ERCOT德州西部 + PJM俄亥俄州；
3. MISO候选utility + PJM俄亥俄州；
4. 资源型站点 + 北弗吉尼亚/其他需求侧边缘节点。

优点：
- 可在同一国家法律和数据治理框架内建立多区域服务；
- 能研究不同ISO/RTO、电力市场、utility和州政策的资源差异；
- 更容易统一运维、供应链和客户支持体系。

风险：
- ERCOT、MISO、PJM均存在大型负荷增长和电网扩建挑战；
- 不同RTO不自动意味着完全独立的输电/气候/供应链故障域；
- 水资源、州级许可、税收、市场规则和跨州数据/合同需逐项核验。

### 路线C：中国大陆 + 美国跨国双区域

优点：
- 地理、部分自然灾害、能源市场和法律辖区可形成更大程度的外部隔离；
- 可支持全球业务入口、区域数据驻留和跨大洲灾备等特定场景。

风险：
- 数据跨境、个人信息/重要数据、行业监管、出口管制、制裁和设备供应链合规；
- 跨大洲WAN时延、带宽、费用、跨境链路故障和运营商依赖；
- 身份、密钥、证书、审计、DNS、时间源和控制面需跨境分区治理；
- 不能默认跨境同步复制、实时GPU调度或热迁移；
- 运维值班、备件、服务合同、财务结算、税务和事故响应复杂度显著上升。

结论：跨国路线只有在明确全球业务需求、数据分级、法律意见和跨境SLO后才进入投资候选，不作为默认方案。

## 3. 组合筛选的反直觉约束

- 中卫 + 庆阳虽然两地不同，但同属西北资源型区域，可能共享干旱/风沙/高温等气候相关性，且跨区网络/供应链可能集中；必须先做相关性和共同故障域分析。
- 和林格尔 + 乌兰察布地理接近，不能仅凭不同园区或城市认定独立。
- PJM俄亥俄 + PJM北弗吉尼亚虽地理不同，但共享RTO市场规则和部分区域输电/天气风险；需核验上级输电和服务区边界。
- MISO + PJM分属不同RTO，也不能把RTO边界当作完整的电气隔离；需检查互联、共同气候、天然气供应和跨区传输。
- ERCOT + MISO/PJM可能形成更强电力市场差异，但必须核实具体互联点、应急支援边界和跨区网络，且德州西部水资源/接入申请风险较高。

## 4. 建议的业务角色划分

### 资源型区域
承担可迁移训练、批处理、离线分析、渲染、Checkpoint密集作业和可延迟的数据处理。任务必须支持暂停、恢复、排队和本地故障自治。

### 需求侧区域
承担低时延推理、用户数据入口、缓存/存储、业务控制、区域API和对本地法规有要求的工作负载。

### 两区域共同承担
控制面、安全审计、身份和密钥管理必须按区域自治设计；跨域协调通过授权租约、Owner Epoch、Fencing Token、撤销状态和对账流程完成。WAN断开时不能发生双重授权或无主写入。

## 5. 组合评分和否决

沿用G2-06.13组合独立性100分权重：
- 电网/变电站/上游电源25；
- 水源/流域/冷却15；
- 光纤/运营商/PoP/管道20；
- 自然灾害相关性15；
- 法律/市场/供应链10；
- OEM服务与备件5；
- 时延、复制与恢复可达性10。

组合分数建议不低于70；任一未缓解共同关键单点直接No-Go。评分不能代替业主风险接受和专业工程审查。

## 6. 当前推荐决策

暂不选择国家/城市组合。先完成：
1. 中国大陆C1/C2/C3/C4四个资源型区域的L2/L3证据；
2. 美国U1/U2/U3/U4/U5分区和utility映射；
3. 两国同国组合和跨国组合的业务需求/法律/时延对照；
4. 通过G2-06.13硬门槛后再做组合评分。

## 7. 结论

G2-06.14 RC0保留三条路线。正式选址不能由“绿电多、气候冷、电价低”单一指标决定，必须由可兑现供电、合法水资源、物理网络、灾害隔离、业务时延、合规和五年TCO共同决定。
