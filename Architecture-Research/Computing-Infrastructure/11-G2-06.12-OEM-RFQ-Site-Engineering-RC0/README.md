## 重要规格纠偏与未决事项

1. **HPE GB300 电力 Whip SKU 不能简单按地区二分。** QuickSpecs 同时列出 400V/60A NA（S6X18A/S6X19A）、400V/60A INTL（S6X20A/S6X21A）和 480V/60A NA（S6X22A/S6X23A），还区分 Top Feed/Bottom Feed。必须按站点电源制式、OEM 订货配置和机柜进线方向选型。
2. HPE QuickSpecs 给出 132kW nominal TDP、约 155kW EDPp、母线建议支持 192kW；NVIDIA Enterprise RA 的组件页另写 full rack requiring up to 142kW。两者口径需 HPE/NVIDIA 在正式报价与供电输入表中解释。192kW 仅作初步母线规划输入，不是平均耗电或已批准总负荷。
3. HPE GB300 NVL72 48U rack 尺寸 2495×600×1068mm，Fully Loaded (with PGW) 约 3300lb；Dell IR9048 rack 尺寸与重量不同，不能共用同一基础/通道设计。
4. Lenovo N1380 DS0187 当前公开资料列出 SC750 V4、SC777 V4；此前研究中的 SC755 V5 + N1380 组合必须取得 Lenovo 对准确 Machine Type/Model、tray、固件和水路的兼容性书面确认，不能视为已验证组合。
5. XDU1350 的 1.3MW 额定冷量及最多支持 8 个 NVL72 rack 的产品声明，不等于整机 N+1 或本项目冷却可用性已验收。
6. HPE、Dell、Lenovo 的 NVL72 rack-scale 系统不是可互换的“同一机柜”：机架宽深、重量、供电、布线、液冷接头、管理接口和 OEM 服务边界均需分别回填。

## 当前冻结状态

- 已确认：架构角色、候选平台家族、网络/存储/控制平面隔离原则、双区域设计方向。
- 待 OEM 书面确认：最终订货 SKU、完整 BOM、端口映射、QVL、功率曲线、热负载曲线、液体边界、机柜尺寸/重量/点载荷、固件/软件支持、服务 SLA、交期。
- 待站点确认：国家/地区、城市、园区、供电电压/频率、上级电网容量、当地规范、建筑/消防/结构条件、冷源/水源、运营商资源、许可和水权。
- 不允许：把候选设备数量当成采购定单；把厂商最大额定值当成运行负载；把公开规格当作项目 QVL；未取得 Owner 与工程师签字就宣布施工冻结。

## 建议使用流程

架构基线 → 发出 RFI/RFQ → OEM 回填 → 技术偏差审查（TBE）→ 商务比较（CBE）→ 样机/工厂验收（FAT）→ 到货核验 → 现场验收（SAT）→ 单星/区域/双区域联调 → 业主与独立见证签署。
