# G2-06.12｜双区域十星工程采购技术需求书（RFQ）

**文档状态：** RC0 询价草案  
**适用对象：** GPU OEM、CPU/HPC OEM、存储 OEM、网络 OEM、液冷 OEM、数据中心总包/机电集成商  
**采购范围：** 两个区域，每区域五个逻辑星位；设备、网络、供配电、液冷、部署服务与五年支持。

> 供应商必须逐项填写 OEM 设备响应与偏差矩阵。未回答、仅引用产品宣传页、以“标准配置”替代准确 SKU、未列明例外和假设，均视为未响应。任何替代配置均须列明型号、SKU、数量、差异、性能影响、功率/冷却影响、交期和生命周期。

## 1. 项目概况

项目采用双区域部署，每区域包含：
- A1/B1 GPU 计算：1 套 72-GPU 级 GB300 NVL72 rack 候选；
- A2/B2 CPU/HPC：1 套 N1380 enclosure 与配套 SC-Series compute tray 候选；
- A3/B3 容量存储：2 台高密度存储服务器候选；
- A4/B4 Control/Support：3 台控制类服务器候选；
- A5/B5 Edge/Security：2 台边缘/安全类服务器候选；
- 独立 GPU Fabric、CPU North-South、Storage、Control/OOB、WAN 网络；
- CDU、一次/二次液路、供配电、UPS、PDU/母线、消防、监控、机房配套。

逻辑星位不等于独立机柜；最终机柜数量、U 位、通道、管路和配电由完整 OEM 机械/电气/液冷图确定。

## 2. 设备路线与询价分组

### 2.1 GPU rack 主候选与替代

| 路线 | 候选平台 | 供应商必须回填 |
|---|---|---|
| 主候选 | HPE GB300 NVL72，公开 SKU S7K95A / Base Rack S6C60A | 完整订货 BOM、rack SKU、Compute Tray、ConnectX-8、BlueField-3、OSFP port mode、Power Whip、Power Shelf、Manifold、CDU/接口套件 |
| 替代 | Dell PowerEdge XE9712 + IR9048 | 完整 rack/Sled BOM、PS33、DLC 选件、4×OSFP/每 sled 的端口定义、DPU、管理、线缆、冷却与供电图 |
| 替代 | Lenovo GB300 NVL72 Type 7DJV | 完整机柜/托盘/电源架/液冷/网络 BOM；逐项标明该 SKU 是否可在目标国家/地区销售与维护 |

不得将 HPE、Dell、Lenovo 的 tray、power shelf、busbar、manifold、quick disconnect、firmware 或光模块混用，除非厂商书面认证。

### 2.2 CPU/HPC
- 当前参考：Lenovo ThinkSystem N1380 Neptune enclosure + SC-Series trays。
- 供应商必须明确 N1380 兼容的 compute tray Machine Type/Model、CPU/GPU、内存、NIC、PCS 数量、48V busbar、SMM3/BMC 管理和固件支持。
- DS0187 当前公开列出的可用计算类型包含 SC750 V4、SC777 V4；如报价 SC755 V5 或其他型号，须提交 Lenovo 签署的兼容性证明。
- 每个 N1380 enclosure 的 PCS、N+1 能力、输入支路、液体介质和运行温度分别核对，不把“可容纳”视为“已认证”。

### 2.3 存储
- 当前参考：Dell PowerEdge R7725xd + KIOXIA LC9 E3.L 高密度 NVMe 候选。
- 供应商提交准确服务器 SKU、盘位背板、盘数量/容量/固件、NVMe PCIe lane、RAID/HBA、NIC、热插拔、盘级耐久度、断电保护、故障域、可用容量计算、备件与保修。
- 必须分别报价原始容量、可用容量、纠删码/副本开销、元数据、快照、重建空间和性能基线。
- 未完成 QVL 前，KIOXIA LC9 不得标记为 Dell 平台已认证盘。

### 2.4 Control / Edge / Security
- 当前参考：Dell PowerEdge R9815；控制类 3 台/区域、边缘/安全类 2 台/区域为架构估算，不是最终数量。
- 供应商提交 CPU、内存、Boot/数据盘、NIC、DPU/加速卡、PSU、BMC、TPM、Secure Boot、Redfish/IPMI、固件生命周期、远程管理隔离和服务 SLA。
- 控制平面需说明 3 节点/5 节点 HA 的故障域、仲裁、恢复和容量依据；不得仅以“支持集群”替代架构证明。

## 3. 网络与光互连询价

### GPU Fabric
- 每区域选择一条 GPU 网络技术路线：Spectrum Ethernet/RoCE 双平面，或 Quantum InfiniBand 双平面。
- 主参考：NVIDIA Spectrum-6 SN6600 Plane-A/B；替代参考：Quantum-X800 Q3400-RA Plane-A/B。
- 不允许把 RoCE 与 InfiniBand 拼接成同一个 GPU Fabric。
- 供应商提交 switch SKU、NOS/firmware、port speed、OSFP/QSFP 类型、buffer、PFC/ECN/QoS（RoCE）或 UFM/SM（IB）、电源/散热、许可、支持期限和可扩展多 rack 拓扑。
- 逐端口提交 NIC—交换机连接表，包含 rack/tray/NIC/port、switch/port、rail/plane、模块 SKU、波长、光纤类型、连接器、长度、FEC、DOM 阈值和 QVL。

### 其他网络
- CPU North-South、Storage、Customer/WAN、Control/Support、OOB/Facility 分层。
- 供应商提交端口/吞吐/超售比、冗余路径、路由策略、VRF/VLAN、ACL、加密、管理面隔离、运营商物理路由多样性和链路 SLA。
- OOB/BMC/设施管理不得暴露于租户网络；不得将 OOB 接口简单并入生产 VLAN。

## 4. 供配电与设施要求

### GPU rack 电力输入
HPE QuickSpecs 当前公开口径：
- 8 个 Power Shelf；
- 每个 Power Shelf 一条 Power Whip；
- 每个 Power Shelf 最高 33kW；
- 132kW nominal TDP、约 155kW EDPp；
- 建议母线规划支持 192kW EDPp。

NVIDIA Enterprise RA 组件页另列整 rack 最高需电约 142kW。供应商必须解释各功率数字的定义、输入侧/直流侧边界、配置条件、峰值持续时间、冗余状态和计量点。不得将 8×33kW=264kW 当作实际输入负载。

HPE QuickSpecs 列出的 Power Whip 选项包括：
- 400V/60A NA Top/Bottom Feed：S6X18A / S6X19A；
- 400V/60A INTL Top/Bottom Feed：S6X20A / S6X21A；
- 480V/60A NA Top/Bottom Feed：S6X22A / S6X23A。

选型须以站点供电制式、频率、相制、连接器、进线方向、支路保护和 OEM 订单为准，不能简单按“北美=480V、中国=400V”推断。

### CPU/HPC
Lenovo N1380 公开资料给出最多 4×15kW Titanium PCS、N+1、54kW DC enclosure capacity、约 58kVA 输入视角；输入可按每 PCS 32A 或两 PCS 共用 63A、380—480V 三相连接等配置。供应商须提交准确 PCS 数量、线路分配、输入功率曲线和单 PCS 失效降额表。

### 供配电响应
提交：
- 电气单线图、保护整定、短路电流、接地、谐波、功率因数和弧闪研究输入；
- UPS/发电机/ATS/母线/PDU 的容量、效率、旁路和维护模式；
- 关键 IT 双 PSU A/B 馈电映射；
- NVL72 8 条 Whip 到 Power Shelf 的逐路映射；
- 最大/典型/待机/启动/瞬态功率和建议设计裕量；
- 单路失电、UPS 检修、发电机切换、黑启动和受控关机方案。

## 5. 液冷与机电工程响应

供应商必须提供一次侧/二次侧边界、P&ID、介质、水质、材料、温度、压力、流量、压降、热负载曲线、过滤等级、泵曲线、泄压、排气/排水、快接、漏液检测、阀门联锁和维护隔离条件。

HPE XDU1350 公开资料列出 1.3MW 额定冷量、最多 8 个 NVL72 rack 的支持说明。供应商必须明确：
- 该能力的额定工况和环境边界；
- 单 CDU 与 1+1 CDU 的设备/管路/控制/供电差异；
- 泵组 N+1 与 CDU 整机 N+1 的区别；
- 单 CDU 维护/故障时允许的降载与停机策略；
- 与 N1380 液冷回路是否可以共用设施一次侧，必须分别证明二次侧隔离和介质兼容。

## 6. 机房空间、结构与运输

供应商提交：
- 设备外形、维护空间、运输包装、门/电梯/坡道限制、重量、重心、脚轮/支撑点和点载荷；
- 机柜静载/动态载荷、地板/楼板/架空地板和抗震固定要求；
- 机柜顶部/底部进线、桥架、光纤弯曲半径、管路走向和维护抽出空间；
- 设备到货路径、吊装点、搬运设备、开箱/安装/调试计划；
- 满水、PGW、线缆、备件和后续扩容的额外质量。

## 7. 软件、固件、供应链与安全

必须提交：
- 全部软件/固件组件及版本矩阵、支持操作系统、驱动、OFED/NCCL/NVSHMEM/管理工具版本；
- Secure Boot、TPM、Root of Trust、BMC、Redfish/IPMI、审计日志、漏洞响应和固件签名机制；
- SBOM、已知漏洞公告、补丁支持周期、EOL/EOS 日期；
- 设备序列号、制造地、原产地、出口分类/许可适用性、供应链追溯和防篡改运输；
- 远程支持入口、数据出境/遥测位置、账号授权、双因素认证和会话审计；
- 本地备件、RMA 时效、驻场服务、故障替换 SLA 和服务覆盖区域。

## 8. 商务与 TCO 响应

供应商分列：
- 设备 CAPEX、网络/光模块/线缆、机柜/电力/液冷、安装调试；
- 软件许可、订阅、支持、培训、驻场、维保和延保；
- 能耗、冷却辅机、水耗、耗材、滤芯、冷却液、备件和故障更换；
- 交付周期、价格有效期、付款里程碑、税费、运输保险、关税和进口合规；
- 五年成本模型的价格基准日、币种、汇率、通胀/涨价、折现率、残值和假设。

不得用公开零售价格替代企业 OEM 项目报价；所有报价须注明税费、运保、安装和软件是否包含。

## 9. 必交付图纸和数据

1. 完整 BOM 与准确订货 SKU。
2. Rack elevation、外形/重量/重心/点载荷图。
3. 电气单线图与每支路负载表。
4. 液冷 P&ID、设备二次侧接口图和热负载曲线。
5. 网络拓扑、逐端口连接表、光模块/线缆 QVL。
6. 固件/驱动/软件兼容矩阵。
7. FAT、SAT、性能与故障演练方案。
8. 运维手册、备件清单、服务 SLA 与 EOL/EOS 生命周期。
9. 安全/供应链/原产地/出口合规声明。
10. 五年 TCO 与全生命周期成本假设。

## 10. 采购放行条件

- 技术偏差全部关闭或由 Owner 书面接受；
- 完整 SKU、BOM、QVL、端口表、功率表和热工数据一致；
- 机房电力/冷却/结构/网络可承载并由专业工程师签署；
- 站点法规、许可、出口与数据合规已确认；
- FAT/SAT、故障恢复、备件与 SLA 可执行；
- 五年 TCO 使用可核验报价与实测输入；
- 采购、架构、设施、安全、网络、计算和财务 Owner 共同签署。
