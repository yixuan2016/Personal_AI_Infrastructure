# G2-06.21 跨版本基线纠偏与覆盖关系说明

**版本：** RC0.1  
**核查日期：** 2026-11-23  
**适用范围：** PAI 算力底座 G2-06.9 至 G2-06.21 研究主线  
**状态：** 研究候选纠偏说明；不构成业主批准、采购授权或施工图冻结

## 1. 为什么需要本说明

G2-06.9 至 G2-06.20 的早期硬件、RFQ、容量与设施模型主要以 GB300 NVL72 为 GPU 机柜参考。G2-06.21 ADR-08 已将 GPU 平台路线升级为新一代多路线候选。若只追加 G2-06.21 而不更新旧版 README、RFQ、BOM、功率模型和容量输入，会形成同一主线中“GB300 仍是唯一主平台”与“Vera Rubin/Helios 已成为新候选”的版本冲突。

本说明建立统一版本优先级，并明确旧资料的保留范围。

## 2. 当前 GPU 平台优先级

| 优先级 | 平台 | 当前定位 | 主要边界 |
|---|---|---|---|
| P1 | Lenovo NVIDIA Vera Rubin NVL72，7DJVCTO4WW | 当前主参考候选 | 72 GPU；36 Vera CPU；18 Compute Tray；9 NVLink Switch Tray；4×110kW Power Shelf；MaxP约227kW、MaxQ约187kW机柜TDP；液冷/空气热捕获约96%/4% |
| P2 | AMD Helios MI455X rack-scale | 异构替代候选 | 72 MI455X/MI450X；约31TB HBM4；UALink/UALoE；Vulcano 800；DS6010；UEC/Ethernet scale-out；整柜OEM SKU待定 |
| P3 | GB300 NVL72（HPE S7K95A/S6C60A、Dell XE9712/IR9048、Lenovo Type 7DJV） | 过渡/兼容对照 | 72 B300、36 Grace、18 Compute Tray、9 NVLink Switch Tray；保留既有OEM BOM与设施资料 |

**平台选择规则：** 每个区域每次只能选择一条 GPU rack 路线；不得把不同平台的 GPU、网络、Power Shelf、CDU、机柜或功率数据拼成一个虚构的混合 BOM。P1/P2/P3 都是候选，尚未通过项目级 OEM QVL、价格、交期、基准测试和业主签署。

## 3. GPU 功率与热工口径

### P1 Vera Rubin

- Lenovo LP2527 给出 MaxP 约 227kW、MaxQ 约 187kW 机柜 TDP。
- 4×110kW Power Shelf 合计 440kW 是 DC 侧输出能力，不是 AC 输入、实际耗电、平均 IT 负载或 utility firm MW。
- 液冷/空气热捕获约 96%/4% 是产品参考边界，不代替项目 CDU 流量、压降、温度、冗余和 P&ID。
- 最终 AC 曲线、功率因数、峰值持续时间、Whip/支路、4M3 冗余和地区 CTO/MTM 仍需 Lenovo 书面确认。

### P2 AMD Helios

- Schneider Electric SC26 AMD Helios reference design 支持最高约 246kW/rack；该数值仅是设施供电/冷却参考设计边界，不是 AMD/OEM 实际 AC 输入或现场实测功耗。
- Helios 整柜 AC 输入、MaxP/MaxQ 热负荷、液冷流量/压降、CDU 边界、机柜重量、冗余与地区 SKU 仍需 AMD/OEM/ODM 提供签署配置。
- AMD Helios 当前官方页面同时出现 23.3TB/s（Rack Highlights）与 19.6TB/s（Compute Tray）单 GPU HBM 带宽，页面内口径冲突仍存在；不得自行选择较高值冻结，需 AMD 书面澄清。

### P3 GB300

- HPE 132kW nominal TDP、约155kW EDPp、192kW busway planning，以及 NVIDIA RA 的 up-to-142kW 表述，均保留为 GB300 专属的不同测量/设计口径。
- 这些数值不得套用于 Vera Rubin 或 Helios；也不得将 192kW 母线规划等同于实际 AC 功耗或站点 MW。

## 4. 其他设备与平台边界

### CPU/HPC

- Lenovo SC755 V5 + N1380 作为当前 CPU/HPC 主参考候选。
- Lenovo LP2495（2026-11-13 更新）已明确列出 SC755 V5 受 N1380 enclosure 支持；EPYC 9976-S7、9756-S7 为 Non-Controlled 支持候选，9966-S7/9996-S7 为 Controlled。
- 9956 未列入当前 SC755 V5 支持 SKU 表，不得仅凭 SP7 插槽推断兼容。
- N1380 4×15kW PCS、N+1、54kW DC enclosure capacity 和约58kVA输入视角是设备/机箱参考口径，不等于项目 AC 实测或区域供电容量。
- 项目级 CTO/MTM、CPU SKU、内存 QVL、固件、PCS、水路、地区供货和保修仍待 Lenovo 书面确认。

### 存储

- Dell R7725xd + 40× KIOXIA LC9 245.76TB E3.L 是容量层候选；每台理论原始容量 9.8304PB，两台合计约19.6608PB raw/区域。
- Raw capacity 不等于保护后可用容量；EC/副本、热备、元数据、运行水位、坏盘、重建空间和增长预留需由 Storage Owner 输入并验收。
- Micron 9650/9550、KIOXIA CM7-V 等保留为热/温层候选，不能与容量层直接混算性能或成本。

### 网络

- Vera Rubin：NVLink 6 本地机柜 Scale-up；ConnectX-9/BlueField-4；Spectrum-6 RoCE 与 Quantum-X800 InfiniBand 是两条独立的 Scale-out 候选路线。
- Helios：UALink/UALoE 本地 Scale-up；Vulcano 800 与 Celestica DS6010；UEC/Ethernet Scale-out。需独立核对端口、光模块、拥塞控制、固件与运维栈。
- GB300：NVLink 5、ConnectX-8/BlueField-3 等旧路线保留为 P3 过渡对照。
- 不得把 NVLink、UALink、RoCE、InfiniBand 和 UEC 当成同一互通 Fabric。

## 5. 容量模型的保留与覆盖

- 72 GPU/rack 仍可作为 P1/P2/P3 的算术比较基线。
- 72×8,760 = 630,720 GPU-h/年/区域；双区域 1,261,440 GPU-h/年只是日历容量上限，不是可用、已分配、验收有效或可售 GPU-h。
- 有效 GPU-h 必须进一步扣除维护/故障不可用、调度空闲、作业失败、质量/SLO不合格、数据等待和跨区域限制。
- G2-06.19 的容量公式结构可保留；其 GB300 专属功率值由本说明和 G2-06.21 平台功率矩阵覆盖。
- G2-06.20 的 BOM 核验应按 P1/P2/P3 分路线记录，不得把 GB300 的机柜功率套用于所有路线。

## 7. Owner 输入与验收状态

- G2-06.20 的 40 项业主输入台账当前为 40/40 未答复；状态均为 Hold。候选型号不等于 Owner 批准值。
- 区域A/B法域、工作负载、GPU有效利用率、存储保护、RPO/RTO、Utility firm MW、AC曲线、PUE/WUE、水权、物理光纤路由、预算、建设路线和退出成本仍待真实输入。
- 站点、园区、Utility、OEM、承包商和业主均未完成项目级签署；没有真实供应商回函、正式报价、现场测量、双站点故障注入或 FAT/SAT 结果。
- 因此本说明只统一研究候选基线，不冻结采购、建设、站点、预算或投运参数。
