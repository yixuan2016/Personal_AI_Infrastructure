## 重要边界

- “十星”是每区域五个逻辑资源域，不是十台固定物理服务器。
- 每区域一套GB300 NVL72为参考候选；两区域GPU合计理论配置规模不代表可跨区域组成一个NVLink域。
- HPE 132kW名义TDP、约155kW EDPp、192kW母线规划建议必须分别记录；192kW不是实测平均IT负载或utility已分配容量。
- Lenovo N1380 54kW N+1 DC chassis capacity不是AC输入功率；Vertiv XDU1350 1.3MW是额定冷量，不是CDU用电功率。
- 每区域两台R7725xd、每台40×245.76TB LC9仅对应约19.6608PB/区域原始十进制容量；可用容量取决于保护、预留、元数据和文件系统策略。
- Spectrum-6 Ethernet/RoCE双平面为主参考，Quantum-X800 InfiniBand为独立替代路线；不得拼接成一个混合Fabric。
- Site A/B当前只是逻辑区域代号；国家、城市、园区、法域和真实地块均未冻结。
- 任何数值SLO、RPO/RTO、功率MW、网络带宽、冷却能力、WUE/PUE和预算均须由业务/业主/专业Owner确认并有证据。
