# G2-06.9｜十星 CPU/GPU/存储/网络设备型号参考选型

**资料核查日期：** 2026-11-13  
**状态：** RC0 候选；待设备、OEM、站点与采购 Owner 评审  
**目的：** 回应十星架构中 CPU、GPU、存储和网络设备型号不够明确的问题，建立可核查的候选型号基线。

## 1. 选型原则

- 按工作负载选设备，不按厂商理论峰值简单叠加。
- 明确区分单芯片、加速卡、OAM 模块、服务器、整机柜系统和交换机。
- CPU/GPU/存储/网络型号必须同时核验接口、驱动/固件、拓扑、功耗、散热和 OEM 支持。
- 设备公开规格只用于候选筛选；最终以采购 SKU、OEM QVL、固件版本和现场验收为准。
- 十颗算力星不要求同构，应允许 GPU 密集型、CPU 密集型、存储密集型和网络/边缘型站点分工。

## 2. CPU 候选型号

### 2.1 AMD EPYC 9006 SP7

| 型号 | 核心/线程 | 频率 | 默认 CPU 功率 | 内存/I/O | 架构定位 |
|---|---:|---|---:|---|---|
| AMD EPYC 9956 | 256C / 512T | Base 1.7GHz，Boost up to 4.1GHz | 400W（可配置功率范围 400–600W） | 16 通道 DDR5 RDIMM/MRDIMM；PCIe 6.0 x96 | 高线程密度与能效候选 |
| AMD EPYC 9996 | 256C / 512T | Base 2.55GHz，Boost up to 4.1GHz | 600W（CPU Power Range 400–600W） | 16 通道 DDR5 RDIMM/MRDIMM；PCIe 6.0 x96 | 高核心密度、高功率候选 |
| AMD EPYC 9966 | 192C / 384T | Base 3.05GHz，Boost up to 4.1GHz | 600W（CPU Power Range 400–600W） | 16 通道 DDR5 RDIMM/MRDIMM；PCIe 6.0 x96 | 更高基础频率的并行计算候选 |
| AMD EPYC 9756 | 128C / 256T | Base 3.2GHz，Boost up to 4.1GHz | 500W（CPU Power Range 320–500W） | 16 通道 DDR5 RDIMM/MRDIMM；PCIe 6.0 x96 | 核心数与频率平衡候选 |

AMD 官方规格列出 EPYC 9006 SP7 系列最高 256 核、16 通道内存、PCIe 6.0；9956 产品页列出 2026-11-10 发布日期，AMD 于同日宣布 SP7 平台出货。新平台仍需核验各 OEM 主板、BIOS、散热器、MRDIMM QVL 和操作系统支持。

**初步建议：**
- Agent Sandbox、CPU 密集型并发和控制/服务节点：优先评估 EPYC 9956。
- 对单线程性能和高频更敏感、且电力/冷却预算充足：评估 EPYC 9996 或 9966。
- 不应仅凭 256 核数值决定选型；需要跑实际 Agent、数据库、编译、网络协议和 GPU Host 工作负载。

### 2.2 Intel 对照型号

| 型号 | 核心/线程 | 基础/最大频率 | TDP | 内存 | I/O |
|---|---:|---|---:|---|---|
| Intel Xeon 6980P | 128C / 256T | 2.0GHz / 3.9GHz | 500W | 12 通道 DDR5-6400 或 MRDIMM-8800 | PCIe 5.0，96 lanes，2S |

Xeon 6980P 作为 Intel Granite Rapids 服务器处理器对照项，适合纳入既有 Intel 生态、软件认证和 OEM 供货比较；其 PCIe 代际与 EPYC 9006 SP7 不同，不能直接按 CPU 核数横向判优。

## 3. GPU 候选型号

### 3.1 NVIDIA Blackwell Ultra

| 型号/形态 | 配置 | 公开规格要点 | 适用场景 |
|---|---|---|---|
| NVIDIA GB300 NVL72 | 72× Blackwell Ultra GPU + 36× Grace CPU，整机柜液冷 | 20TB GPU Memory；GPU Memory Bandwidth up to 576TB/s；NVLink 总带宽 130TB/s | 大模型训练、推理和高通信密度工作负载 |
| NVIDIA HGX B300 | 8× Blackwell Ultra GPU 的服务器平台 | 2.1TB Fast Memory；总内存带宽约 62TB/s；单 GPU 270GB HBM3E、7.7TB/s | 8-GPU 标准服务器形态、分布式训练与推理 |

GB300 NVL72 是机柜级 NVLink 域，不能视为普通 8-GPU PCIe 服务器。HGX B300 是 8-GPU 平台，应单独核验 OEM 服务器、GPU TDP、供电和冷却设计。

### 3.2 AMD Instinct MI350

| 型号/形态 | 配置 | 公开规格要点 | 适用场景 |
|---|---|---|---|
| AMD Instinct MI355X OAM | 单 GPU OAM 模块 | 288GB HBM3E；8TB/s；最高 1400W TBP | 高性能 AI/HPC，需液冷与 OAM 平台 |
| MI355X 8-GPU Platform | 8× MI355X OAM | 2.3TB HBM3E；聚合理论带宽 64TB/s | 高密度 AMD GPU 计算节点 |
| AMD Instinct MI350P PCIe | PCIe 加速卡 | 144GB HBM3E；4TB/s；最大 600W，可配置 450W | 既有 PCIe 服务器扩展、较小规模 GPU 节点 |

MI355X OAM 与 MI350P PCIe 不是可直接互换的形态。采购前必须核验服务器主板、供电连接器、PCIe 槽位、GPU 互连拓扑、ROCm 版本和整机散热。

### 3.3 前瞻型号观察

NVIDIA DGX Vera Rubin NVL72 官方资料列出 72× Rubin GPU、36× Vera CPU、20.7TB HBM4、总内存带宽 1,400TB/s、NVLink 带宽 216TB/s，以及 ConnectX-9 800Gb/s 网络配置。该型号纳入下一代设备观察清单；当前不能仅凭已发布数据表认定十星 OEM 供货、部署软件和现场液冷已经完成验证。

## 4. 存储设备候选

| 层级 | 明确型号 | 关键规格/特点 | 建议用途 |
|---|---|---|---|
| Gen6 高性能 NVMe | Micron 9650 | PCIe Gen6；顺序读取最高约 28GB/s；5.5M+ IOPS；支持 E1.S/E3.S 形态 | GPU 数据供给、热缓存、Checkpoint/Burst Buffer（需工作负载验证） |
| Gen5 高性能 NVMe | Micron 9550 PRO/MAX | PCIe Gen5；PRO 容量最高 30.72TB、MAX 最高 25.6TB；PRO 最高 1 DWPD、MAX 最高 3 DWPD | 通用企业 NVMe、缓存与数据节点 |
| Gen5 NVMe | Solidigm D7-PS1010 | PCIe 5.0；面向混合与主流企业工作负载 | 通用数据节点与缓存层候选 |
| 双端口企业 NVMe | KIOXIA CM7-V | PCIe 5.0/NVMe 2.0；双端口；容量最高 12.8TB；3 DWPD | 双路径存储、数据库和高可用企业负载 |
| 冷数据 HDD | Seagate Mozaic 4+ 44TB | HAMR 平台，44TB；官方称已在两家超大规模云客户处量产部署 | 对象存储冷层、归档和低频数据 |

**存储分层建议：**
- 热层：本地 NVMe / GPU 邻近缓存，优先低时延与高带宽。
- 温层：企业 NVMe 池，承担共享数据集、模型制品、Checkpoint 和高频对象。
- 冷层：高容量 HDD 对象存储，承载低频数据和长期归档。
- 元数据、日志、事务账本与大对象数据分层部署，避免单一存储池同时承担所有延迟与容量目标。
- SSD 型号的容量、DWPD、断电保护、双端口、固件和 OCP 兼容性必须按 SKU 核验；不能只看顺序带宽。

## 5. 网络设备候选

### 5.1 GPU Scale-out：InfiniBand

| 型号 | 公开规格 | 角色 |
|---|---|---|
| NVIDIA Quantum-X800 Q3400-RA | 4U，144×800Gb/s 端口，72 个 OSFP cages | 大规模 AI/HPC 计算网络 |
| NVIDIA Quantum-X800 Q3401-RD | 4U，144×800Gb/s 端口，面向 DC 供电机柜配置 | 与 Q3400-RA 相同网络代际的不同供电/机柜形态 |
| NVIDIA ConnectX-8 InfiniBand SuperNIC | 最高 800Gb/s，PCIe Gen6 | GPU 服务器高速网络接口 |

Quantum-X800 官方资料列出 144 个 800Gb/s 端口，并支持 SHARP、Adaptive Routing 和拥塞控制。是否采用 InfiniBand，需由 MPI/Collective、训练规模、运营团队能力和应用生态决定。

### 5.2 GPU/存储 Scale-out：Ethernet

| 型号 | 公开规格 | 角色 |
|---|---|---|
| NVIDIA Spectrum-6 SN6600 | 128×800Gb/s OSFP 端口；102.4Tb/s 交换容量 | 800G Ethernet Leaf/Spine 候选 |
| NVIDIA Spectrum-6 SN6800 | 512×800Gb/s CPO 端口；409.6Tb/s 交换容量（按厂商数据表） | 高密度 CPO 交换系统候选 |
| NVIDIA ConnectX-8 Ethernet SuperNIC | 总带宽最高 800Gb/s；Ethernet 端口组合需按具体 SKU 核验 | 服务器 RoCE/以太网接口 |
| Broadcom Tomahawk 6 | 102.4Tb/s 交换 ASIC | 第三方 OEM 交换系统芯片候选，具体整机型号待 OEM 确认 |

Spectrum-X 是完整的以太网 AI 网络方案，不能只凭交换芯片带宽认定 RoCE 网络可用。必须验证 ECN、PFC 使用边界、拥塞控制、队列、遥测、路由收敛和多租户隔离。

### 5.3 网络分层

- Scale-up：机柜内部 GPU 互连，GB300 使用 NVLink；AMD OAM 平台使用其对应 Infinity Fabric 互连。
- Scale-out：GPU 节点间采用 InfiniBand 或经过验证的 RoCE Ethernet。
- Storage Fabric：NVMe-oF/对象存储数据路径独立规划，避免与 GPU 集合通信争用。
- Control/Management：ADS、SCO、RCP、LCP、BMC、监控与设施管理独立隔离。
- WAN：跨区域广域网不等同于 GPU Fabric，不承诺跨区域同步训练，除非专项实测通过。

## 6. 十星参考配置建议

不为十颗星指定完全相同的设备清单。建议按站点角色组合：

| 站点角色 | CPU | GPU | 存储 | 网络 |
|---|---|---|---|---|
| 通用/控制型星 | EPYC 9956/9996 或 Xeon 6980P | 可无 GPU 或少量 PCIe GPU | 企业 NVMe | 双路径 100/400GbE，控制网络隔离 |
| GPU 密集型星 | GPU Host CPU 按 OEM 平台配置 | GB300 NVL72 / HGX B300 / MI355X 平台择一 | Micron 9650 + 9550 | Quantum-X800 或 Spectrum-X |
| CPU/HPC 型星 | EPYC 9996/9966/9756 | 按任务需要选加速卡 | NVMe Scratch + 温数据层 | 400/800G 按通信需求配置 |
| 存储型星 | EPYC 9956/9756 或经认证的 Intel 平台 | 非必需 | Micron 9550、Kioxia CM7-V、Seagate 44TB 冷层 | 独立 Storage Fabric |
| 边缘/网络型星 | EPYC 9G76/9556 等右尺寸 CPU | 可选 MI350P PCIe | 企业 NVMe | 多运营商 WAN、DPU/高速 NIC、带外管理 |

上表是角色画像，不是已冻结的单星 BOM。每个站点的具体 CPU 数量、GPU 数量、DIMM 容量、SSD 数量、交换机端口和电源规格必须根据任务画像、机柜功率和网络拓扑计算。

## 7. 不应混淆的型号与指标

1. GB300 NVL72 是 72 GPU 机柜级系统，HGX B300 是 8 GPU 平台。
2. MI355X 是高功率 OAM 模块，MI350P 是 PCIe 卡。
3. EPYC 9956 与 9996 同属 SP7 但功率档不同；主板/散热 QVL 不可互推。
4. Micron 9650 Gen6、9550 Gen5、Kioxia CM7-V 和 Solidigm PS1010 的容量/耐久/端口配置不同。
5. Quantum-X800 是 InfiniBand；Spectrum-X 是 Ethernet。
6. Tomahawk 6 是交换 ASIC，不等于某个已确定的交换机整机型号。
7. Seagate 44TB Mozaic 4+ 的超大规模客户量产状态，不等于所有地区和 OEM 已开放常规采购。

## 8. 采购与验收前置清单

- OEM 服务器/机柜准确 SKU、主板、BIOS、BMC、PSU、风扇/冷板和保修条款。
- CPU QVL、DIMM/MRDIMM 料号、内存频率、NUMA、PCIe lane 分配与 CXL 支持。
- GPU OAM/PCIe 形态、驱动、固件、ROCm/CUDA、MIG/隔离、互连和整机功耗。
- SSD SKU、容量、DWPD、PLP、双端口、固件、SMART/OCP 遥测和热插拔。
- HDD SKU、容量、接口、转速/功耗、振动和机箱背板兼容性。
- NIC、交换机、光模块、线缆、FEC、光纤类型、端口速率和兼容清单。
- GPU/存储/网络 Fabric 拓扑、超售比、拥塞控制和故障切换。
- 机柜输入功率、液冷供回水、CDU、热密度、冗余与设施联锁。
- 真实任务基准、故障演练、固件升级和回滚计划。

## 10. 结论

目前可以明确给出 CPU、GPU、存储和网络的具体候选型号，但不能在缺少任务画像、OEM 兼容性、站点功率/液冷预算、供应商报价和现场网络测量的情况下冻结十星采购 BOM。

G2-06.9 的交付目标是把“设备型号明确”与“型号已验证可部署”严格区分，下一步需要按单星角色建立 OEM 级配置清单和功率/散热/网络端口预算。
