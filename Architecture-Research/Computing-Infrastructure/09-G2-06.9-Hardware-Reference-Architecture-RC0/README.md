## 选型边界

1. 明确型号不等于已采购、已供货或已通过 OEM 兼容性认证。
2. GPU 机架级系统、单 GPU OAM/PCIe 卡、CPU 插槽处理器和交换芯片必须区分，不能混为同一级设备。
3. GB300 NVL72 与 HGX B300、AMD MI355X OAM 平台、MI350P PCIe 是不同集成形态。
4. Micron 9650 是 PCIe Gen6 数据中心 SSD 候选；Micron 9550、Solidigm D7-PS1010、Kioxia CM7-V 是 PCIe Gen5 产品候选。
5. Seagate Mozaic 4+ 44TB 作为冷数据容量层候选；当前官方资料说明其已在部分超大规模客户处量产部署，不能直接推断为所有地区均可常规采购。
6. Quantum-X800 InfiniBand 与 Spectrum-X Ethernet 是不同网络路线，不应默认混合成同一无差别 Fabric。
7. NVIDIA Vera Rubin NVL72 纳入前瞻型号观察；在供应、OEM、软件栈和液冷设施确认前，不作为已验证的十星基线。

## 阶段结论

建议以“CPU 通用/控制节点 + GPU 加速节点 + NVMe 热数据层 + HDD 冷数据层 + 独立 GPU Scale-out 网络 + 管理/设施网络”构建异构参考架构。最终型号和数量必须由任务画像、区域电力/冷却预算、机房密度、供应链和兼容性测试决定。
