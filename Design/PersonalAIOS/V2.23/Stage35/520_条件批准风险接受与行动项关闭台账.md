# 520｜条件批准、风险接受与行动项关闭台账

**父基线：** V2.22-Draft / 00—503  
**目标基线：** V2.23-Draft / 00—523  
**状态：** Candidate / Pending；不推断Owner批准，不授权工程实现

## 1. 目的
将批准条件、例外和遗留风险转成可验证行动项，防止附条件批准被误读为完全批准。

## 2. 范围与议题
Action Record记录Action ID、Decision ID、Condition/Risk ID、描述、Owner角色、责任人、期限、验证方法、证据、依赖、状态、升级规则和关闭证据。条件状态：Proposed、ApprovedWithConditions、InProgress、Verified、Expired、Failed、Closed。

## 3. 权威边界与控制要求
风险接受由有权角色作出；S0风险不得通过普通业务接受绕过；安全、隐私、法律或不可恢复删除风险须专业审查；条件未验证不得计入无条件冻结完成。

## 4. 所需证据与验收
风险依据、影响主体、补偿控制、期限、复审触发器、决定权威和关闭证据。当前无真实条件批准记录。

**统一状态声明：** 本文件为审议准备材料；未取得真实Owner原始反馈和有效批准证据前，相关事项保持Pending/Proposed，不得升级为Approved或Freeze。
