# 508｜M08 IA审议工作流与六对象实例权威核对表

**父基线：** V2.22-Draft / 00—503  
**目标基线：** V2.23-Draft / 00—523  
**状态：** Candidate / Pending；不推断Owner批准，不授权工程实现

## 1. 目的
核验M08作为六个S1 OT候选Instance Authority时，对实例身份、创建、更新、状态、版本和生命周期写入的责任边界。

## 2. 审议范围
- Source：Source实例、Locator引用、状态和版本。
- SourceSnapshot：不可变采集封套创建和引用登记。
- RawAsset：逻辑资产身份与血缘；物理字节由M02负责。
- KnowledgeAsset：逻辑身份、内容版本引用和生命周期。
- ExtractionRun：运行记录、输入输出引用、状态和追踪。
- Chunk：Chunk身份、父版本、ChunkSet关系和生命周期。

## 3. 权威边界与控制要求
- M08不签发M02物理Handle、不持有密钥、不写M06 Assertion/Verification、不创建M18 PolicyDecision。
- Locator可访问不等于合法授权；Run Succeeded不等于内容真实。
- IA不自动取得TDA/SA、Custodian或Policy Authority。

## 4. 所需证据与验收
- 对象写入责任矩阵、Command/Event Owner、版本/并发/幂等规则、Snapshot Correction、删除协同和引用解析样例。
- 每个字段的实例写入者、授权Actor和状态守卫明确。
