# 512｜跨Owner联合审议会议规程与议程

**父基线：** V2.22-Draft / 00—503  
**目标基线：** V2.23-Draft / 00—523  
**状态：** Candidate / Pending；不推断Owner批准，不授权工程实现

## 1. 目的
解决一个议题涉及多个权威角色时的边界和依赖，不以会议人数或多数表决替代权威分工。

## 2. 审议范围
- 会前提供议题ID、字段/契约ID、原始反馈、证据、选项、反方风险、决定Owner和消费者影响。
- 120分钟议程：基线/权限确认、反馈陈述、语义澄清、Owner分别陈述、方案比较、原子处置、行动分派、决议确认。
- 角色包括Decision Owner、Co-review Owner、Professional Reviewer、Facilitator、Recorder和Evidence Reviewer。

## 3. 权威边界与控制要求
- Facilitator/Recorder不代替Owner决策。
- 会议草稿须由Decision Owner确认。
- 异议必须保留，跨权威冲突按494号升级。

## 4. 所需证据与验收
- 会前材料、参会角色、原始意见、决议文本、条件/例外、行动项和会后确认。
- 未确认决议只能记NotesCaptured或PendingConfirmation，不得标OwnerApproved。

**统一状态声明：** 本文件为审议准备材料；未取得真实Owner原始反馈和有效批准证据前，相关事项保持Pending/Proposed，不得升级为Approved或Freeze。
